# VXmp3 1.0.0

- Chỉnh sửa thẻ nhạc hàng loạt, gồm ảnh bìa và thông tin album.
- Đo âm lượng và cân bằng gain MP3 mà không mã hóa lại âm thanh.
- Hoàn tác bằng bản lưu gốc; giữ nguyên file nếu phát hiện đã được sửa bên ngoài.
- Mở lại nhanh tối đa 5 thư mục gần đây từ thanh trên cùng.
- Kiểm tra và cài bản cập nhật ngay trong ứng dụng.
